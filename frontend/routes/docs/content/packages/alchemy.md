# Alchemy

Infrastructure as code with Alchemy.

All the deploy code is written in /infra/deploy.ts using [Alchemy](https://alchemy.run/). Alchemy is a pure typescript IaC library. Read the [author's blog post](https://alchemy.run/blog/2025-04-08-decade-long-journey/) for more on the motivation behind it and why I think it's a great library.

The initial deploy script deploys to Cloudflare Workers/Pages.
